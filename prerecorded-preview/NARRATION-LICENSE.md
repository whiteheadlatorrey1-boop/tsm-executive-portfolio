# Narration provenance

Voice: Piper en_US-ljspeech-medium, contributed by Bryce Beattie.
Model: public-domain release declared by the creator.
Dataset: LJ Speech; text, audio and annotations are declared public domain in the United States, with no use restrictions and optional attribution.

Primary sources:
- https://brycebeattie.com/files/tts/
- https://keithito.com/LJ-Speech-Dataset/

The creator's release and unrestricted dataset terms support the intended original portfolio narration. No separate generated-audio restriction was found in those terms. Public-domain status is stated on a US basis and is not a warranty of worldwide rights clearance. No speaker endorsement or impersonation is claimed.

The voice was generated locally using Piper and ONNX Runtime. The runtime, model weights, training data and development tools are not distributed in this static folder. Only generated MP3 audio and the public presentation files are included. Publishing generated narration is distinct from redistributing runtime software or model weights.

All spoken scripts are the portfolio's synthetic WHAT TO SAY captions. No private records or enterprise operating data were used. Production release remains ON HOLD.
